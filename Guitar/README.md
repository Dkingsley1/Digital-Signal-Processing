# Guitar DSP Projects

## Guitar/Bass Tone Capture Engine

The actively developed system is in
[`guitar_bass_tone_capture_engine`](guitar_bass_tone_capture_engine/).

It includes:

- simultaneous clean-DI and amplifier/microphone capture;
- live waveform, spectrum, level, pickup, and blower-switch monitoring;
- MLX production modeling and isolated PyTorch/NAM research workflows;
- fixed-rig probe capture, latency and polarity alignment, cabinet separation,
  dry A/B auditions, and held-out promotion guards;
- PyCharm run configurations and command documentation.

Recordings, trained models, generated renders, logs, virtual environments, and
research-volume data are deliberately excluded from GitHub. They are local
runtime artifacts and can be large or hardware-specific.

The original `Bass Amp Tone Capture Engine` file remains in this directory as
the compact legacy prototype.
